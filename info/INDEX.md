# Wedding Planning Knowledge Base Index

## How to Use
1. Keep each topic updated in its own file.
2. Record key decisions in section `WED-18`.
3. Track unresolved items in section `WED-19`.
4. Use section IDs in tasks, chats, and meeting notes.
